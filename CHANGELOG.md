# Changelog

1.0.13:
- Fixed the logo image not loading up in the game.

1.0.12:
- For the Tier 3~7 Armors, reference the vanilla Minecraft armor layer textures instead of unmodified copies of them.
  - This will also help thin the mod's resulting file size as well.

1.0.11:
- No changes to the mod code at all, the only change is to fix a few metadata inconsistencies with the 1.20.1 forge version when compared to the port versions.
  - Also the forge version was missing MinecraftForge as a dependency in the metadata so 1.0.11 fixes that.

1.0.10:
- First public release.
- All Armors & Tools from this mod (except the God Tier versions) now damage when used in the Crafting Table. Previously they would vanish entirely using significantly more resources than intended. The resources required to craft each Scarletite Block was made to consume a lot of resources to promote world exploration and farming to prevent "finishing" the game too fast.
- 1.20.1 was originally used to make the Mod, as such I decided to also add 1.21.1 and 26.1.2 port versions of the mod as well on this version.

1.0.9 and older:
- Private developmental builds.
